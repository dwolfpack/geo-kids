# Content Studio

Personal content, organized by platform, drawn from real experience: QA and
manual testing, engineering management, monolith-to-microservices migrations,
managing people through transitions, working in Israel's tech industry, and
parenting alongside side projects — including the real `geo-kids` project in
this repo (a 195-country kids' geography game).

See `BRIEF.md` for the shared voice/content rules every piece follows:
first-person, humanized, no AI/automation-as-topic, grounded in real project
details (the country-data schema, the validation script, real bugs found,
the difficulty-tier redesign).

## What's here

| Platform  | Pieces | Format                          | Images |
|-----------|--------|----------------------------------|--------|
| LinkedIn  | 8      | `post.md` (150-350 words)        | 1 SVG diagram per post |
| Medium    | 5      | `article.md` (900-1500 words)    | 2 SVG diagrams per article |
| X         | 8      | `thread.md` (6-10 tweets)         | 1 SVG per thread |
| Instagram | 8      | `caption.md` (100-200 words)      | 1-2 SVG carousel slides per post |

Each platform folder has its own `INDEX.md` listing every piece with a
one-line description — start there to pick what to publish next.

## Topics covered across the set

- Manual and exploratory testing as a craft (not "the step before automation")
- The country-data expansion: real bugs (missing Albania, wrong Hebrew
  capital names, a hyphenation bug), the schema, the validation script
- The difficulty-tier redesign: population-based (30/30/30/5/5) to
  recognizability-based (39/39/39/39/38)
- Monolith vs. microservices testing: how ownership, seams, and failure
  modes actually change
- Managing people through re-orgs and transitions, keeping trust
- Working in Israel's tech industry: reserve duty (miluim), intensity,
  resilience
- Parenting and side projects: patience, product thinking, staying hands-on

## Publishing notes

- SVGs are self-contained (no external image references) and sized per
  platform convention (800x500 LinkedIn, 900x550 Medium, 1200x675 X,
  1080x1080 Instagram carousels). Export to PNG/JPEG at publish time if a
  platform doesn't accept SVG uploads directly.
- Text files are plain text/markdown, ready to paste — LinkedIn and
  Instagram captions have no markdown syntax in them; Medium articles use
  markdown headers as Medium's editor expects; X threads are one tweet per
  line, blank line between tweets.
